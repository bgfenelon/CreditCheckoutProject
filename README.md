# 💳 Credit Checkout Project

Este projeto tem como objetivo desenvolver um fluxo de cadastro de cartão de crédito em tela, incluindo validações de formulário, experiência responsiva e simulação de um checkout moderno.

A aplicação foi construída com foco em boas práticas de front-end, organização de componentes e experiência do usuário.

---

## 🚀 Funcionalidades

- Cadastro de cartão de crédito
- Validação de campos em tempo real
- Feedback visual para o usuário
- Layout responsivo (desktop e mobile)
- Simulação de fluxo de pagamento / checkout
- Componentização e organização de código

---

## 🛠️ Tecnologias utilizadas

- TypeScript
- JavaScript
- HTML5
- CSS
- Conceitos de UI/UX
- Responsividade

---

## 📱 Responsividade

O projeto foi desenvolvido considerando diferentes tamanhos de tela, garantindo boa experiência tanto em dispositivos móveis quanto desktop.

## ▶️ Como executar o projeto

1. Clone o repositório

```bash
git clone https://github.com/bgfenelon/CreditCheckoutProject.git
```

2. Acesse a pasta do projeto

```bash
cd CreditCheckoutProject
```

3. Instale as dependências

```bash
npm install
```

4. Execute o projeto

```bash
npm run dev
```
